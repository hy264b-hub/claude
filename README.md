# 원고지 · Wongoji

SillyTavern UI 테마입니다. 흰 종이와 먹, 청회색으로 인쇄된 원고지 칸만으로 대화를 한 편의 원고처럼 보여 줍니다.

## 구성

- **원고지 띠**: 메시지마다 정사각 칸과 줄 사이 틈, 이중 테두리로 된 원고지 석 줄이 붙습니다. 원고지에 지은이 이름을 쓰는 관례를 따라 이름은 셋째 줄 오른쪽에 끝 두 칸을 비우고 한 칸에 한 글자씩 적습니다. 채팅 번호도 첫째 줄에 같은 방식으로 적고, 띠 아래에는 `原稿用紙`라고 작게 인쇄해 두었습니다.
- **폴라로이드**: 아바타는 흑백 폴라로이드로 띠 위에 비스듬히 겹쳐 놓입니다. 마스킹 테이프와 손글씨 이름이 붙고, 마우스를 올리면 사진이 컬러로 돌아옵니다.
- **원고 본문**: 본문도 원고지 줄 위에 쓰입니다. 글줄이 칸 줄 가운데에 앉고, 줄 사이 틈이 행간이 됩니다. 문단은 원고지 쓰기처럼 한 칸 들여 씁니다.
- **문장 표현**: 대사와 본문은 먹색, 지문과 속마음은 청회색입니다. 인용(`>`)은 책 뒤표지의 제사(題辭)처럼 가운데 정렬된 청회색 상자로, 장면 전환(`---`)은 `＊`로 보입니다.
- **색**: 흑백과 청회색만 씁니다. 유저 원고지는 아주 옅은 청회색이고, 그림자와 블러는 없습니다.
- **상단 메뉴**: 아이콘을 작게 줄이고 책 머리말처럼 이중 괘선으로 구분했습니다.

서체(Google Fonts): 고운바탕(본문), 나눔명조(이름·제목·인용), 나눔손글씨 펜(폴라로이드), IBM Plex Mono(번호·날짜).

> 한글 본문 서체는 글자마다 너비가 달라(문장부호와 띄어쓰기가 특히 좁습니다) CSS만으로는 본문을 한 칸에 한 글자씩 맞출 수 없습니다. 그래서 본문은 칸 줄의 리듬만 따르고 세로 칸선은 아주 옅게 깔았습니다. 칸에 정확히 맞추는 것은 이름과 번호뿐입니다.

## 설치

1. `themes/원고지 Wongoji.json`을 내려받습니다.
2. SillyTavern → **사용자 설정(User Settings)** → **UI Theme**에서 가져오기(Import) 버튼을 눌러 파일을 선택합니다.
3. 테마 목록에서 `원고지 Wongoji`를 고릅니다.

> Chat Style은 **Flat**으로 두세요. 테마가 이 값을 자동으로 맞춥니다. Bubbles나 Document 스타일과는 함께 쓰도록 만들지 않았습니다.

## 취향대로 조정하기

모든 값은 Custom CSS 맨 위 `:root` 변수에 모여 있습니다.

| 변수 | 용도 |
| --- | --- |
| `--wg-desk`, `--wg-paper`, `--wg-paper-user` | 배경, 원고지 종이, 유저 원고지 색 |
| `--wg-print`, `--wg-print-line` | 원고지 인쇄색(청회색) |
| `--wg-quote`, `--wg-em` | 대사와 지문 색 |
| `--wg-body-col` | 본문 세로 칸선. `transparent`로 두면 가로 줄만 남습니다 |
| `--wg-photo-filter` | 폴라로이드 필터. `none`으로 두면 컬러 사진이 됩니다 |
| `--wg-cell`, `--wg-gap`, `--wg-name-size` | 머리 원고지 칸, 줄 사이 틈, 이름 글자 크기 |
| `--wg-text`, `--wg-body-cell`, `--wg-body-gap` | 본문 글자 크기, 본문 칸 높이, 줄 사이 틈. 설정의 Font Scale도 함께 반영됩니다 |
| `--topBarIconSize` | 상단 메뉴 아이콘 크기 |

## 개발

원본 CSS는 `src/wongoji.css`에 있습니다. 수정한 뒤 아래 명령으로 테마 JSON을 다시 만듭니다.

```sh
node scripts/build.mjs
```
