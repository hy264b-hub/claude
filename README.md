# 원고지 · Wongoji

SillyTavern UI 테마입니다. 대화를 원고지에 옮겨 적듯 보여 주고, 장식보다 문학적인 분위기와 가독성을 먼저 챙겼습니다.

## 구성

- **원고지 띠**: 메시지마다 칸이 그려진 띠가 있고, 이름을 한 칸에 한 글자씩 적습니다. 오른쪽 위에는 채팅 번호와 날짜가 들어갑니다.
- **폴라로이드**: 아바타가 살짝 기울어진 폴라로이드 사진으로 띠 위에 겹쳐 놓이고, 마스킹 테이프와 손글씨 이름이 붙습니다.
- **원고 카드**: 본문은 옅은 괘선이 그어진 흰 종이 위에 쓰입니다. 대사는 청보라 잉크, 지문과 속마음은 옅은 먹색, 나머지 글은 먹색입니다.
- **좌우 반전**: 캐릭터는 왼쪽에 폴라로이드와 흰 원고지를, 유저는 오른쪽에 폴라로이드와 하늘빛 원고지(일력 색)를 둡니다.
- **절제**: 그림자와 블러를 없애고, 상단 메뉴와 입력창은 책 머리말처럼 이중 괘선으로만 구분합니다.

서체(Google Fonts): 고운바탕(본문), 나눔명조(이름·제목), 나눔손글씨 펜(폴라로이드), IBM Plex Mono(번호·날짜).

## 설치

1. `themes/원고지 Wongoji.json`을 내려받습니다.
2. SillyTavern → **사용자 설정(User Settings)** → **UI Theme**에서 가져오기(Import) 버튼을 눌러 파일을 선택합니다.
3. 테마 목록에서 `원고지 Wongoji`를 고릅니다.

> Chat Style은 **Flat**으로 두세요. 테마가 이 값을 자동으로 맞춥니다. Bubbles나 Document 스타일과는 함께 쓰도록 만들지 않았습니다.

## 취향대로 조정하기

모든 값은 Custom CSS 맨 위 `:root` 변수에 모여 있습니다.

| 변수 | 용도 |
| --- | --- |
| `--wg-paper`, `--wg-sheet` | 배경 종이와 본문 카드 색 |
| `--wg-band`, `--wg-band-user` | 캐릭터와 유저의 원고지 띠 색 |
| `--wg-quote`, `--wg-em` | 대사와 지문 색 |
| `--wg-ruled` | 본문 괘선 색. `transparent`로 두면 괘선이 사라집니다 |
| `--wg-cell`, `--wg-name-size` | 원고지 칸 크기와 이름 글자 크기 |
| `--wg-photo`, `--wg-tilt` | 폴라로이드 크기와 기울기 |
| `--wg-text`, `--wg-lh` | 본문 글자 크기와 행간. 설정의 Font Scale도 함께 반영됩니다 |

## 개발

원본 CSS는 `src/wongoji.css`에 있습니다. 수정한 뒤 아래 명령으로 테마 JSON을 다시 만듭니다.

```sh
node scripts/build.mjs
```
