◇ 이런 테마예요

메시지 한 통이 원고지 한 장이 됩니다. 캐릭터의 사진은 폴라로이드로 원고지 띠 위에 비스듬히 놓이고, 이름은 원고지 칸에 한 자씩 적힙니다. 본문은 틀 없이 종이 위에 바로 써서 읽기 편하게, 장식은 여백에만 조용히 두었어요.

색은 흑백과 청회색뿐이고, 그림자와 블러는 없습니다. 화이트와 다크 두 가지가 있으며, 디자인은 같고 색만 다릅니다.

◇ 설치

  1. 첨부한 White 또는 Dark 테마 파일(.json)을 받습니다. 둘 다 받아 두고 바꿔 가며 써도 돼요.
  2. 실리태번 → 사용자 설정(User Settings) → UI Theme 옆 가져오기(Import) 버튼으로 파일을 고릅니다.
  3. 글꼴을 불러오는 @import 안내 창이 뜨면 확인을 눌러 주세요.
  4. 테마 목록에서 원고지 Wongoji를 고르면 끝!

◇ 함께 쓰면 좋은 설정

  • Chat Style은 Flat으로 두세요. (테마가 자동으로 맞춰요)
  • Language를 한국어로 두면 날짜가 2026년 10월 13일 오전 7:13처럼 나와요.
  • Message Token Count, Message Timer, Model Icon을 켜도 원고지 여백에 자연스럽게 들어가요.
  • 폴라로이드 글귀, 장식 종류(새와 꽃 · 새 · 꽃), 심플 모드, 본문 글꼴과 크기, 첫 글자 칸 켜고 끄기는 테마 옵션에서 바꿀 수 있어요.
업데이트할 때 — 실리태번은 같은 이름의 테마를 다시 가져오지 않아요. 테마 이름에 버전 번호가 붙어 있으니, 새 파일을 가져온 뒤 목록에서 새 번호를 고르고 예전 버전은 삭제해 주세요.
